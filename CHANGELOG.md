# Changelog

All notable project changes are documented in this file.

The project follows [Semantic Versioning](https://semver.org/). Until the first stable release, minor versions may include graph-schema or API changes.

## [Unreleased]

### Added

- Product-grade repository policy, continuous integration, dependency updates, and secret scanning.
- English-only documentation validation with `README.ja.md` as the translated introduction.

### Changed

- Public project naming and clone instructions now use PICG.
- Web editor version aligned with the native components at `0.1.0`.
- Unity sample scenes now regenerate cooked previews instead of storing embedded meshes and result payloads.
- Native mesh tests no longer request unused fixed-size JSON output buffers.

### Removed

- Unreferenced backup graphs, placeholder subgraphs, duplicate reference media, stale research drafts, and third-party sample media without confirmed redistribution rights.

## [0.1.0] - Unreleased

- Initial public development release of the native PCG runtime, local MCP server, Web editor, Unity integration, graph schema, reusable library, and curated examples.
