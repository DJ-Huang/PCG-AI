# Support

Use GitHub Discussions or a focused issue for installation questions, graph-authoring questions, and reproducible defects.

Before opening an issue:

1. Check `docs/getting-started.md` and the component documentation.
2. Reproduce the problem with the smallest available graph.
3. Include the operating system, commit or version, compiler, Node.js version, and Unity version when relevant.
4. Remove API keys, local paths, private assets, and user data from logs and screenshots.

Security vulnerabilities must follow `SECURITY.md` and must not be disclosed in a public issue.
