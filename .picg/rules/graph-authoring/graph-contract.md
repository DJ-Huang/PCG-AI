# PCG graph authoring contract

The maintained contract is [shared graph authoring](../../../.agents/skills/shared/graph-authoring.md); live operations use the [MCP contract](../../../.agents/skills/shared/pcg-mcp.md). This retrieval entry routes to those sources rather than maintaining a second workflow.

Use current schemas, explicit compatible pin handles, stable IDs, unique node titles, top-down layout, metre-scale dimensions and synchronized root parameters. Preserve unrelated state and omitted payloads. Layout is position-only and applies to affected scopes after a coherent structural pass.

Load object-specific rules only for that object or mechanism. Roads, facade clearances and oriented scatter are not universal constraints for every prop. Golden Graphs provide reviewed construction examples; demos are not strategy authorities.

Match the user's requested scope. A node fix or blockout does not require complete-asset production. For visual changes, validate/cook and inspect current target output; static validation alone does not prove appearance. Only a complete-asset request uses the [complete-asset contract](../../../.agents/skills/shared/complete-asset-workflow.md).
