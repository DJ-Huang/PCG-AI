# Roadmap

PICG is under active development. This roadmap communicates direction and is not a delivery guarantee.

## 0.1 series

- Stabilize the graph schema and migration rules.
- Keep Web and Unity authoring behavior aligned with the native runtime.
- Expand deterministic validation, sample coverage, and release automation.
- Package optional media and large sample assets separately from the core source tree.

## Before 1.0

- Publish compatibility and deprecation policies.
- Provide a self-contained runtime deployment path without a same-machine development sidecar.
- Establish versioned release artifacts and upgrade documentation.
- Validate an additional host integration using the same graph contract.

See GitHub issues for accepted work and current priorities.
