# Node Algorithm Reference

The complete, generated inventory is [Node Reference](../node-reference.md). Use that document and `schema/node-manifest.json` for current node names, pins, properties, defaults, and categories.

The main algorithm families are:

- **Generation:** points, grids, primitives, splines, and heightfields.
- **Structure:** hulls, proximity graphs, triangulation, spanning trees, Voronoi, and pathfinding.
- **Geometry:** transforms, sweeps, lofts, booleans, bevels, subdivision, grouping, and merging.
- **Sampling and scatter:** surfaces, splines, terrains, density filters, and prototype placement.
- **Attributes:** create, copy, filter, wrangle, promote, and delete domain values.
- **Materials and UVs:** UV generation, texture projection, material definitions, and explicit assignment.
- **I/O:** host inputs, third-party generation, output, preview, and export.

Node labels may resemble tools in other DCC applications, but the PICG manifest and tests define actual behavior.
