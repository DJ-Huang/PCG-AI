# PICG Unity Samples

- `Demos/` contains curated end-to-end scenes and the graph gallery.
- `Showcases/` contains finished reference-driven assets.
- `Validation/` contains focused visual regression scenes.

Generated review scenes must go to `Assets/PICG-Workspace/` instead of this directory. Promote only a finished, documented sample into this tree.

See the project-level `Unity/README.md` for setup and validation instructions.
