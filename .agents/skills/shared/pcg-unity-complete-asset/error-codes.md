# Unity error routing

Use the shared [asset error table](../asset-errors.md). Unity-specific failures include project/import mismatches, pink shaders, transient mesh/material references and prefab reload defects; a successful Web cook does not resolve them.

Repair through [Unity integration](unity-integration.md) and use [Unity review](../../pcg-graph-authoring-unity/unity-review.md) without discarding scene changes.
