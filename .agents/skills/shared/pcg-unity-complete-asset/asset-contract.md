# Unity AssetSpec

For a requested finished asset, use the outcome contract in [complete-asset delivery](../complete-asset-workflow.md). Record `assetId`, `intent`, reference sources/viewpoints, `scale`, important `modules`, `geometryDoD`, `materialSlots`, allowed `variation`, `outputs` and `acceptance` in a compact plan or asset-spec file. Honor any existing consumed sidecar format.

Unity outputs include the valid `.pcg`, applicable texture sources/import settings, persistent mesh/material assets, the requested prefab and current Unity review evidence. Preserve the front axis, metre/stylized scale, root parameter defaults and hierarchy. A named slot may use an intentional flat-colour material, but not an accidental default or pink shader.

Use durable asset-specific paths and persistent Unity asset references, not scene-only objects. A temporary scene subject or screenshot is not prefab delivery. Reload the actual prefab in the intended project and report missing verification honestly. Preserve existing acceptance criteria and exceptions; numerical scoring applies only when defined by that contract.
