# Graph stage for a Web asset

Use the shared [graph authoring contract](../graph-authoring.md) and [MCP contract](../pcg-mcp.md), rather than a second platform copy of graph rules.

For visual evidence, use [Web review](../../pcg-graph-authoring-web/web-review.md). Reference reconstruction uses [reference-driven authoring](../reference-workflow.md); generator promises use [generator validation](../generator-validation.md).

For a complete-asset job, hand the verified graph to [geometry validation](geometry-validation.md), then the applicable surface and export stages. A graph-only job does not activate those later stages.
