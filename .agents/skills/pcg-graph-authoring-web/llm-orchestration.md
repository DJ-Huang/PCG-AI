# Web reference-workflow entry

The maintained cross-platform procedure is [reference-driven authoring](../shared/reference-workflow.md). Read it for image reconstruction, not ordinary graph maintenance.

Use [live MCP](../shared/pcg-mcp.md) for the open canvas and [Web review](web-review.md) for saved-graph visual evidence. Read [three-view details](triview.md) only when orthographic constraints apply. Optional planning and evidence helpers are documented in [scripts](scripts.md).

This compatibility reference does not impose an additional pass sequence, mandatory three-view collection, score threshold or full-asset workflow. Existing structured plans retain their schema and agreed acceptance contract.
