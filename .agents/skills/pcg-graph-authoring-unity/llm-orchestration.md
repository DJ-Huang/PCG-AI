# Unity reference-workflow entry

The maintained cross-platform procedure is [reference-driven authoring](../shared/reference-workflow.md). Read it for image reconstruction, not ordinary graph maintenance.

Use [Unity review](unity-review.md) for evidence from the correct project and [scripts](scripts.md) for optional planning and capture helpers. When authoring through an open Web editor, the [MCP contract](../shared/pcg-mcp.md) still protects its document; Unity review remains an independent target check.

This compatibility reference adds no fixed reasoning sequence or iteration quota. Existing structured plans retain their schema and agreed acceptance contract.
