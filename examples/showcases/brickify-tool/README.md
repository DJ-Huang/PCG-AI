# Brickify Tool

`brickify-tool.pcg` is a reusable graph that converts a source shape into a toy-brick-style procedural assembly. The graph intentionally keeps source-mesh inputs as placeholders so users can bind their own geometry.

Read `brickify-asset-spec.md` for dimensions, graph modules, limitations and the acceptance contract.
