# M9 Bayonet Web Graph

`web.pcg` is the Web-oriented M9 bayonet variant. Its source texture remains a Unity sample asset at `Unity/Assets/Samples/PCG-AI/Showcases/M9Bayonet/` so the graph and curated Unity scene share one reference image.

The standalone graph variant is available at `examples/graphs/m9-bayonet.pcg`; the Unity scene and materials are documented in `Unity/README.md`.
