# Code of Conduct

We want PCG-AI to be a constructive, technically curious and welcoming project.

## Expected behavior

- Be respectful and assume good intent while discussing ideas.
- Critique code and decisions, not people.
- Share enough evidence for others to reproduce a claim.
- Respect privacy, attribution and the licenses of third-party code and assets.
- Help make project spaces accessible to people with different backgrounds and experience levels.

## Unacceptable behavior

Harassment, discrimination, threats, sustained disruption, doxxing, sexualized conduct and publishing another person's private information are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove contributions and comments, issue warnings, temporarily restrict participation or permanently ban participants when behavior harms the community. Report conduct concerns privately to the maintainers; do not disclose sensitive personal information in a public issue.

This policy applies to repository discussions, issues, pull requests and other spaces where someone represents the project.
