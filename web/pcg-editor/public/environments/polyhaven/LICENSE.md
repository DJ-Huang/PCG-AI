# Built-in HDRI environments

These HDRI files are sourced from [Poly Haven](https://polyhaven.com/) and are
distributed under the [CC0 1.0 license](https://polyhaven.com/license).

The canonical asset pages, file sizes, and MD5 checksums are recorded in
`src/preview/builtinEnvironments.json`. The bundled files are the 1K Radiance
HDR variants downloaded from the Poly Haven public API.

Attribution is not required by CC0. Source information is retained here so the
assets can be audited and upgraded independently from the editor code.
